PART 2: CONFIGURE SOLANA CLI FOR MAINNET
================================================================================

STEP 2.1: Set Solana CLI to Mainnet
-----------------------------------
Run these commands in your terminal:

  solana config set --url mainnet-beta
  
This tells Solana CLI to use Mainnet instead of Devnet.

STEP 2.2: Set Your Authority Keypair
-----------------------------------
Convert your Authority private key to a Solana keypair file:

1. Create a new file: ~/.config/solana/authority-mainnet.json
2. Paste your Authority private key as a JSON array:
   Example format: [1,2,3,4,5,...]  (32 bytes of your private key)

OR, if you have the 12-word seed phrase:
   solana-keygen recover --outfile ~/.config/solana/authority-mainnet.json

3. Set this as your active keypair:
   solana config set --keypair ~/.config/solana/authority-mainnet.json

4. Verify it's set:
   solana config get
   (Should show your Authority wallet public key)

STEP 2.3: Verify Balance
-----------------------------------
Run: solana balance

You should see approximately 3 SOL

================================================================================
PART 3: DEPLOY THE ANCHOR PROGRAM
================================================================================

STEP 3.1: Download the Program Folder
-----------------------------------
Download the "program/" folder from this Replit project to your local machine.

Place it in a working directory, e.g.:
  ~/projects/myluckysol/program/

STEP 3.2: Build the Program
-----------------------------------
From your terminal, navigate to the program folder:

  cd ~/projects/myluckysol/program
  anchor build

This compiles the Rust smart contract into a deployable binary.
Expected output: "Finished release..." at the end.

Check the binary size (important for cost):
  ls -lh target/deploy/myluckysol.so
  (Should be 200-400 KB)

STEP 3.3: Deploy the Program
-----------------------------------
Run the deployment command:

  anchor deploy --provider.cluster mainnet

This will:
1. Estimate deployment cost (shown in output)
2. Deduct SOL from your Authority wallet for rent + fees
3. Deploy the program to Mainnet
4. Output the PROGRAM ID (save this!)

Example output:
  Program ID: 5mJbYhLfX8eQmYJvJw3kX... (32-character address)

IMPORTANT: Save the Program ID somewhere safe - you'll need it immediately.

STEP 3.4: Verify Deployment
-----------------------------------
Run: solana program show [PROGRAM_ID] --url mainnet-beta

Should show:
  - Program ID: [PROGRAM_ID]
  - Status: Deployed
  - Data size: [SIZE]

Expected cost summary:
  - Deployment fee: ~1 SOL
  - Remaining balance: ~2 SOL

================================================================================
PART 10: TROUBLESHOOTING
================================================================================

ERROR: "Insufficient funds for deployment"
  Solution: Your Authority wallet needs more SOL. 
  Add another 2-5 SOL and try again.

ERROR: "RPC timeout" or "429 Too Many Requests"
  Solution: Your SOLANA_RPC_URL is a public endpoint.
  Set up a private RPC with Helius or QuickNode (add secret).

ERROR: "[SOLANA] Authority keypair failed to load"
  Solution: Your SOLANA_AUTHORITY_PRIVATE_KEY secret is incorrect.
  Verify it's base58-encoded and in the correct format.

ERROR: "WAGA transfer failed: invalid account"
  Solution: Your WAGA Vault ATA doesn't exist.
  Run Step 6.1 to create it.

ERROR: "Game transaction not confirmed"
  Solution: Check your RPC connection (Step 5.3).
  Verify Authority balance (should have at least 0.5 SOL left).
